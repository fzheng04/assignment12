In this module, I learned how to connect my existing database models and Pydantic schemas to functional FastAPI endpoints. I implemented user registration and login endpoints, along with calculation BREAD operations that allow users to create, retrieve, update, and delete calculations stored in PostgreSQL.

Integration testing with pytest helped me understand the importance of testing how different components of an application work together. Rather than only testing individual functions, I tested API requests, response codes, and database changes. Docker provided a consistent testing environment, while GitHub Actions automatically ran the tests and deployed the application to Docker Hub.

My previous experience with Pydantic made implementing the endpoints easier because the schemas already handled input validation, including invalid operation types and division by zero. I also reused the calculation factory to avoid duplicating arithmetic logic.

Security was another important aspect of this module. I used Argon2 to hash passwords during registration and verify them during login. I also ensured that password hashes were excluded from API responses and that duplicate accounts and invalid credentials were handled appropriately.

One challenge I encountered was Docker networking and database connectivity. I also experienced permission issues when running pytest with coverage. Troubleshooting these problems improved my understanding of Docker containers and their environments. Overall, this module helped me understand how database models, validation, API endpoints, testing, and deployment work together to create a functional backend.
